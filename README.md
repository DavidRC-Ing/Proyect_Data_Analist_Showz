# Proyect_Data_Analist_Showz

Proyecto Showz es un análisis integral de datos orientado a optimizar la inversión en marketing y maximizar la rentabilidad de una plataforma de venta de entradas para eventos. El estudio abarca el procesamiento y análisis de grandes volúmenes de datos de visitas, pedidos y gastos publicitarios, permitiendo entender el comportamiento de los usuarios, su ciclo de vida y el impacto de las campañas de adquisición.

A través de cohortes, métricas clave como LTV, CAC, ROMI y AOV, y el análisis por dispositivo y fuente de adquisición, se identifican patrones de conversión, retención y rentabilidad. Los hallazgos permiten fundamentar recomendaciones para mejorar la eficiencia del gasto, priorizar canales de alto retorno y diseñar estrategias de retención y fidelización, asegurando la sostenibilidad y el crecimiento del negocio.
